# Question bank

Ask in this order, at most 3 per round. Skip what is already known.

## Round 1: purpose and people
1. **What should the agent do, in one or two sentences?** (the goal)
2. **Who will use it?** Options: all employees / one team or department / customers or external users / other.
3. **Where should people talk to it?** Options: Microsoft Teams / a web page or intranet / Microsoft 365 Copilot / other.

## Round 2: knowledge and actions
4. **What information should it answer from?** Options: SharePoint sites or documents / files / a website / a database or business app / none (it only takes actions).
5. **What should it be able to do besides answer questions?** Examples: create a ticket, send an email, update a record, start an approval, look up a status. Ask which system each action touches.
6. **Should it act on its own or only when someone asks?** Options: only when asked / also on an event (a new email, a new item) / on a schedule.

## Round 3: access, risk and scale
7. **Who should be allowed to use it, and do they need to sign in?** Options: everyone in the company, signed in / only specific groups / anonymous users.
8. **How sensitive is the data it touches?** Options: public / internal / confidential (HR, finance, customer data) / regulated.
9. **When it cannot help, what should happen?** Options: hand over to a person / create a ticket / just say it cannot help.
10. **Roughly how many people and how many conversations per day?** Options: under 50 / 50-500 / over 500.

## Optional, only if the person is engaged
- What would make this agent a success after one month?
- Is there an existing process, form or team this agent replaces or supports?
- Any legal or compliance rules the agent must follow (retention, data location, approvals)?
